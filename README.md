# 江南大学本科生模拟器

> 在蠡湖畔，把四年过成一场没有存档的青春。

一款本地单机的文字模拟游戏。你将以 2026 级新生的身份进入江南大学，在八个学期、四十八个回合里做选择，最后拿到一份属于自己的毕业档案。

---

## 怎么玩

1. 双击 `index.html` 直接用浏览器打开；或在当前目录运行：

   ```bash
   python3 -m http.server 4173
   ```

   然后访问 <http://127.0.0.1:4173>。

2. 填写姓名、选择生源地、学院和专业，再选一个性格，点击「报到，开始四年」。
3. 每个学期有 6 个回合，阅读事件并做出选择。属性、关系和隐藏条件会改变后续可走的路。
4. 每学期结束会收到一张「教务系统」成绩单，包含 6 门课程、绩点、专业排名、奖学金和辅导员评语。
5. 八个学期结束后，根据绩点、去向、科研/实习/恋爱/社团等隐藏条件，进入 23 种结局之一。

## 核心系统

- **八个学期 / 每学期 6 回合**：共 48 个回合。35 个固定节点（军训、百团大战、第一次小测、转专业、专业分流、竞赛、实习、岔路口、夏令营、秋招、考研、毕设、答辩、毕业）与 71 个随机事件交替出现。
- **20 个学院 / 55 个专业**：按江南大学本科招生网整理，从食品、生工、设计、纺织，到化工、物联网、人工智能、集成电路、智能制造、数字科技、低空技术等；学院决定初始属性、专属事件与毕业去向的底色。
- **六项属性**：绩点、学识、精力、心情、社交、存款。另有学习投入、隐藏 flags 和事件计数。
- **五种毕业去向**：保研、考研、就业、出国、考公。不同去向有独立的冲刺与结果事件。
- **学期结算**：根据学习投入、学识、心情、精力和性格生成 6 门课程成绩，计算加权 GPA、专业排名和奖学金；连续学业预警会触发退学。
- **23 个结局**：普通、稀有、传说、隐藏四档，包含保研顶尖学府、考研上岸/调剂/二战、大厂/国企/体制内、出国、创业、美食博主、设计新星、电竞选手、校园歌手、支教、恋爱毕业等。
- **26 个成就**：军训幸存者、满绩传说、干饭王、图书馆钉子户、脱单成功、第一作者等。
- **自动存档**：进度保存在浏览器 `localStorage`，可随时从标题页继续。结局图鉴与成就跨周目保留。
- **本地音效**：WebAudio 合成，无外部音频资源，可在顶栏或菜单关闭。

## 设计说明

视觉参考了同工作区的 CampusHonorAgent：霞鹜文楷、校园实景虚化背景、蓝色主色、半透明白卡片、细腻的表格与表单。游戏层额外加入了学生证、教务成绩单、毕业档案、朱砂印章和落花动效，让界面更像“江大学生成长系统”，而不是普通后台。

江南大学校徽由用户提供，用于标题页、顶栏、浏览器图标与毕业档案水印；校徽版权归江南大学所有，本作是非官方校园题材同人作品。背景照片与字体来自本地参考项目；字体为 SIL Open Font License 授权的霞鹜文楷。游戏内数值、事件与结局均为虚构创作。

## 已知限制

- 纯本地单机，无后端、无登录、无联网 AI；所有事件为手工编写，不是无限生成。
- 学院与专业按招生页整理，但只收录 20 个四年制本科招生学院；医学院（五年制）与马克思主义学院未纳入模拟。部分卓越班、中外合作项目未单列，55 个专业为游戏收录数。
- 事件与结局是游戏化创作，部分校园细节经过压缩或戏谑处理，不能作为真实教务、保研或就业政策的参考。
- 随机事件采用权重抽取，同一周目不一定能看完所有内容；多周目体验不同。
- 若浏览器禁用本地存储，进度将无法保存，但游戏仍可正常进行。
- 本版使用 v2 存档键（每学期 6 回合）；旧版 4 回合存档不兼容，会在启动时自动清理。
